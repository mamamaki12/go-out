# よりみち鹿児島

鹿児島県内のイベントと常設スポットを探せる、会員登録不要のWebサイト。

- 日付・エリア・ジャンル・移動手段で絞り込み
- 「行きたい」をブラウザ内に保存
- 詳細画面に開催日・営業時間・住所・交通アクセス・駐車場・公式リンク
- 車／公共交通の選択に合わせたGoogle マップ経路検索リンク

## 起動

Node.js 22以上。`npm ci`、`npm run collect`、`npm run serve` を実行し http://127.0.0.1:4174 を開く。

## 情報源

鹿児島県観光サイト「かごしまの旅」のイベント・観光スポットの公開情報。画像は元サイトを参照し、取得元へリンク。開催が終わったと判断できるイベントを除外。開催年の分からないイベントは日付指定の結果から除外する。日付範囲内の休演日や常設施設の臨時休業は自動判定できないため、訪問前に公式情報の確認が必要。

移動手段はアクセス案内の記載で判断する。現在地からの所要時間や交通ダイヤを保証するものではない。検索対象の全施設を網羅しているものではない。

毎日日本時間4:23頃にGitHub Actionsで更新（実行遅延の可能性あり）。手動更新も可能。HTML変更などで収集に失敗した場合は前回データを保持する。

## 公開

GitHub Pagesを使う場合はmainブランチの `/docs` を選択。非公開リポジトリではアカウントのプランによってPagesを利用できないことがある。リポジトリを無断で公開へ変更しない。

## 今後の連携

### ホットペッパー（APIキー設定待ち）

公式グルメサーチAPIで鹿児島県の飲食店を最大1,000件取得するアダプターを実装済み。APIキー未設定の場合は公式観光情報だけを更新します。実APIでの取得確認には有効なキーが必要です。

リクルートWEBサービスでキーを発行した後、GitHubリポジトリの Settings → Secrets and variables → Actions → New repository secret に、名前 `HOTPEPPER_API_KEY` と値を設定します。キーはチャットやソースコードに貼らず、Secretsへ直接登録してください。その後 Actions → Update outing information → Run workflow で初回取得します。APIキーはブラウザに送信しません。利用時はサービスの利用規約に従ってください。

Google Placesは課金設定とAPIキー、保存制限に合わせたサーバー側設計が必要です。Instagramは公式APIで取得できるアカウント・投稿範囲の確認と認証が必要です。この2つの情報取得は未実装です。

公式情報版の次に、Instagram、ホットペッパー、Google Mapsを追加予定。公式APIの利用範囲、APIキー、費用、保存・表示条件を確認してから実装する。現状のGoogle Maps連携は経路検索へのリンクであり、店舗情報の取得ではない。
